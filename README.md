## Assignment Description:
This is a class assignment build where you can convert units of temperature.

### Technologies & Tools Used:
- Java JDK 21
- JavaFX
- Maven
- MariaDB
- Jacoco
- Jenkin
- Docker
### Design Approach & Implementation Method:
Main class launches App, after which App builds the GUI and the program maintains active communication with the database, 
recording every conversion.

### Testing & Quality Assurance Steps:
- Tests return successful
- Ran program on Jacoco with successful tests
- Pipeline on Jenkins is successful

### How to Run:
1. Make sure that you have set up JDK-21, Maven, JavaFX, Jacoco and Jenkins
2. Run mvn build
3. Run program
